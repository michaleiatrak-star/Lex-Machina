# MD5 — TERMINY PROCESOWE

**Treść prawa:** terminy, ich podstawy i reguły liczenia → `view JUR:terminy-procesowe`
(sekcja procedury właściwej dla sprawy i reguły liczenia). Termin bierz z modułu jurysdykcji,
nie z pamięci; ta sama czynność ma różne terminy w różnych procedurach.

**Format:**
```
TERMIN: [czynność]
Data zdarzenia: [DD.MM.RRRR] → Upływa: [DD.MM.RRRR]
Typ: ⚠ ZAWITY · Skutek: [opis] · Podstawa: [art.]
🚨 PILNE — zostały [n] dni roboczych!   (gdy ≤5 dni)
❌ TERMIN UPŁYNĄŁ [n] dni temu — zawity: brak przywrócenia
```
