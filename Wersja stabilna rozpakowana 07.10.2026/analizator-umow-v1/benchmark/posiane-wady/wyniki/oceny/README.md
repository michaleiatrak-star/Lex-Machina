# Oceny konfiguracji

Katalog docelowy dla plików wyniku wygenerowanych zgodnie z
`../../manifesty/instrukcja-sedziego.md` (sekcja „Format wyniku"), jeden plik
`<konfiguracja>.md` na przebieg oceny. Pusty do pierwszego przebiegu — nie
zawiera jeszcze żadnej oceny (F-203(a) dostarcza korpus i protokół; same
przebiegi ocen to F-203(b), otwarte).
