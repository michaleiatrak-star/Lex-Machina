## Goal

Convert G19's PDF-only official source state into a real, bounded verification path.

A downloaded PDF is **not** verification by itself.

Required chain:

`ELI temporal decision → official PDF → bounded local text extraction → title match → reference match → VerificationLedger → HARD GATE`

## Implementation

### Local PDF extractor

`LocalPdfTextExtractor` uses `pdfjs-dist` locally in the backend.

Limits:

- maximum PDF bytes: 16 MiB;
- maximum pages: 600;
- maximum extracted text: 6,000,000 characters;
- OCR: disabled;
- no shell / external converter process.

Fail-closed errors include:

- `PDF_TOO_LARGE`;
- `PDF_TOO_MANY_PAGES`;
- `PDF_TEXT_TOO_LARGE`;
- `PDF_NO_TEXT`;
- `PDF_PARSE_FAILED`.

### Official source verifier

`OfficialLegalSourceVerifier` now:

1. keeps HTTPS + official-host allowlist enforcement;
2. recognizes an official PDF by content type or `.pdf` path;
3. rejects oversized responses before or during extraction;
4. extracts text locally;
5. applies the same expected-act-title check used for text/HTML;
6. applies the same exact legal-reference matcher;
7. writes VERIFIED only after both checks pass.

PDF provenance:

- `verificationMethod = web_fetch_pdf`;
- `sourceFormat = PDF`;
- source tier remains R1 for Sejm/ELI.

The default production verifier now creates a bounded `LocalPdfTextExtractor`; tests can inject a deterministic extractor.

## Temporal integration

G20 does not bypass G19.

The following G19 states may continue into the verifier because they identify a concrete official PDF:

- `CURRENT_TEXT_REQUIRES_PDF`;
- `HISTORICAL_TEXT_REQUIRES_PDF`.

Other temporal failures remain denied, including:

- repealed current t.j.;
- stale descriptor;
- post-t.j. amendments not yet resolved;
- act not in force at historical `asOf`;
- historical amendments after the selected historical text.
