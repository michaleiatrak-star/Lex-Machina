## Implemented

Per case:

```text
cases/<caseId>/secure/artifacts/<artifactId>/
  payload.lme
  manifest.lme
```

Artifact identifiers are opaque `artifact_<128-bit>`.

The encrypted manifest contains:
- filename;
- media type;
- exact SHA-256;
- byte count;
- creation timestamp;
- optional creator;
- sensitivity: PROTECTED or CLEAR_PII;
- storage format.

The filesystem path does not contain the user-visible artifact filename.

## Security properties

- artifact payload encrypted with LME1 / AES-256-GCM;
- separate HKDF purpose for artifact payload and manifest;
- exact case/object/purpose/keyVersion bound in AAD;
- clear-PII final artifacts can be stored without plaintext persistence inside the Lex data directory;
- filename and PII-bearing manifest metadata remain encrypted;
- exact payload can be re-read locally after authorization;
- artifacts participate in case CDK rotation;
- old key fails after rotation.

## Scope
