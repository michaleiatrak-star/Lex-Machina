## Goal

Verify a Sąd Najwyższy case signature through a runtime-owned official resolver rather than letting the model invent or choose a case-law URL.

Provider input:

- exact output claim;
- raw signature;
- `courtFamily=SN`.

The provider cannot supply the source URL.

## Resolver behavior

`SupremeCourtCaseVerifier`:

1. validates/normalizes the SN signature;
2. rejects non-SN repertories before network access;
3. queries the official `sn.pl` resolver;
4. filters near matches;
5. requires exactly one exact signature record;
6. retrieves official full text;
7. decodes the official HTML payload;
8. requires the full text to contain:
   - the exact normalized signature;
   - `SĄD NAJWYŻSZY`;
9. only then writes VERIFIED into `VerificationLedger`.

## Security controls

- runtime-owned `sn.pl` transport;
- HTTPS only;
- redirect targets restricted to `sn.pl` / `www.sn.pl`;
- maximum 3 redirects;
- 60-second request timeout;
- maximum 25 search records;
- bounded base64 payload;
- unsupported court families fail closed;
- multiple exact records return AMBIGUOUS rather than guessing.

Current Joomla `com_ajax` response nesting is supported in both formats:

- legacy: `data[0].raw`;
- current: `data[0].data.raw`.

## Verification provenance

A successful SN identity record contains:

- `kind = case`;
- `status = VERIFIED`;
- `sourceTier = R1`;
- `verificationMethod = web_fetch`;
- `sourceFormat = TEXT`;
- `caseScope = FULL_TEXT`.

The G8 HARD GATE still requires the tool-generated verification marker on the exact signature line.

A fabricated model marker without a ledger record remains blocked.

## Deterministic acceptance

### Exact SN match

- exact signature found;
- near matches rejected;
- full text matches identity;
- VERIFIED ledger record;
- HARD GATE PASS;
- answer released.

### Near match only

- no exact signature;
- no VERIFIED record;
- answer BLOCKED.

### Multiple exact matches

- result AMBIGUOUS;
- runtime refuses to choose.

### Wrong full-text identity

- search record may match;
- full text does not contain the exact signature;
- OUT_OF_SCOPE / BLOCKED.

### Fake verification marker

- provider prints a fake `✅ [VER: ...]`;
- ledger has no verification record;
- G8 blocks the answer.

## Important scope limit

G22 verifies **case identity, metadata and official full-text provenance**.

It does **not** mean that an arbitrary legal thesis, paraphrase, quotation or ratio attributed to the judgment has been verified.

Those propositions require a separate evidence-level verification gate.
