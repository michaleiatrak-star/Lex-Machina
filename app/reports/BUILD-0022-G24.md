## Goal

Allow a paraphrased proposition attributed to a Sąd Najwyższy judgment to be transparently linked to exact official evidence without falsely claiming that the runtime independently proved semantic entailment.

G24 therefore introduces a third evidence status:

- `VERIFIED` — deterministic verification succeeded;
- `SUPPORTED` — proposition is linked to exact verified evidence, but semantic entailment is not independently decided;
- `UNVERIFIED` — verification failed or evidence is insufficient.

`SUPPORTED` is intentionally not `VERIFIED`.

## Provider tool

Runtime exposes:

`verify_case_proposition`

Provider supplies only:

- exact case citation;
- raw SN signature;
- exact proposition text that will appear in output;
- exact support quotation;
- `courtFamily=SN`.

Provider never supplies source URL.

## Verification chain

`provider proposition → runtime SN resolver → exact case verification → exact support-quote verification → proposition/support hash → VerificationLedger(SUPPORTED) → CASE-SUPPORT finalization → HARD GATE`

Successful tool use writes three records:

1. case — `VERIFIED / FULL_TEXT`
2. support quote — `VERIFIED / EXACT_QUOTE`
3. proposition — `SUPPORTED / PROPOSITION_SUPPORT`

## Evidence contract

The proposition record contains:

- exact proposition;
- exact case signature;
- official source URL;
- `caseScope=PROPOSITION_SUPPORT`;
- `evidenceHash`;
- `supportQuoteHash`;
- exact `supportQuote`;
- source tier and fetch timestamp.

The proposition evidence hash binds:

`normalized signature + exact proposition + exact support quote`

Changing either proposition or evidence after tool execution breaks finalization.

## Output markers

A supported proposition must carry all evidence on the same line:

- `✅ [VER: <official-source>, <date>]`
- `✅ [CASE-QUOTE:<quote-hash>]`
- `🔗 [CASE-SUPPORT:<proposition-hash>]`

The exact supporting quotation and exact case signature must also remain on that line.

## Finalization enforcement

G24 adds `caseSupportFindings`.

Fail-closed statuses:

- `MISSING_CASE_SUPPORT_LEDGER`
- `PROPOSITION_TEXT_MISMATCH`
- `SUPPORT_QUOTE_MISSING`
- `CASE_SIGNATURE_MISSING`

Any invalid support marker blocks the whole answer.

## Scope boundary

G24 does not claim to solve general natural-language inference.

It proves:

- identity of the official judgment;
- existence of the exact support quote;
- integrity of the proposition/evidence linkage.

It deliberately does not claim:

- that the paraphrase is the only possible reading;
- that semantic entailment was formally proved;
- that broader legal conclusions follow from the quoted passage.

This distinction is retained in the tool result via:

`semanticVerification=false`.
