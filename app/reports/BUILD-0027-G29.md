## Implemented end-to-end order

`PDF → all-page extraction → OCR fallback → page-level pseudonymization → chunking → local API`

Privacy is applied to the full text of each page **before chunking**. This prevents a chunk boundary from splitting a personal name or identifier before the privacy recognizer sees it.

## Backend

- production OCR and Stanza workers wired in `startLocalServer`;
- `POST /api/documents/ingest` accepts local PDF bytes;
- successful response contains pseudonymized chunks and page/chunk metadata;
- original re-identification map remains only in backend memory;
- OCR/privacy failure returns a sanitized ingestion failure rather than partial document output.
