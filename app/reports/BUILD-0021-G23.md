## Goal

Prevent the model from turning a verified judgment identity into an unverified quotation.

G22 proves:
- exact SN signature;
- metadata;
- official full-text identity.

G23 adds a second, narrower evidence class:

`EXACT_QUOTE`

The quoted text itself must be found verbatim in the already verified official SN full text.

## Provider tool

Runtime exposes:

`verify_case_quote`

Provider supplies only:

- exact case citation;
- raw signature;
- exact verbatim quote;
- `courtFamily=SN`.

Provider never supplies a source URL.

## Verification chain

`provider → verify_case_quote → runtime SN resolver → exact case match → official full text → exact normalized quote match → VerificationLedger → G23 marker integrity → G8 HARD GATE`

Successful quote verification writes two VERIFIED records:

1. `caseScope=FULL_TEXT`
2. `caseScope=EXACT_QUOTE`

The quote record includes:

- `caseSignature`;
- `evidenceHash`;
- official source URL;
- R1 source tier;
- fetched timestamp.

## Output markers

The tool returns two markers:

- normal case verification marker:
  `✅ [VER: <official-source>, <date>]`
- quote evidence marker:
  `✅ [CASE-QUOTE:<20-hex-hash>]`

The exact quote, exact case signature and both markers must stay on the same line.

## Finalization enforcement

G23 extends finalization with `caseQuoteFindings`.

For every `CASE-QUOTE` marker, finalization requires:

1. a VERIFIED ledger record;
2. `caseScope=EXACT_QUOTE`;
3. exact matching `evidenceHash`;
4. exact verified quote text present on the same line;
5. matching case signature present on the same line.

Fail-closed statuses:

- `MISSING_CASE_QUOTE_LEDGER`;
- `QUOTE_TEXT_MISMATCH`;
- `CASE_SIGNATURE_MISSING`.

Any one of these blocks the entire answer.

## Audit

## Scope boundary

G23 verifies **verbatim quotations only**.

It does **not** yet authorize free-form propositions such as:

- “SN uznał, że …”
- “SN stwierdził, że …”
- “z orzeczenia wynika, że …”

unless the proposition is itself represented as the exact verified quotation.

A later proposition/semantic-evidence gate may add that capability without weakening exact-quote verification.
