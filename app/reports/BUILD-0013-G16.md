## Implemented

- provider-neutral `verify_legal_reference` tool schema;
- `ToolBroker` network host allowlist;
- official-source allowlist for Polish legal sources;
- credential-free HTTPS only;
- redirects fail closed;
- private/local network targets remain denied;
- fresh official-source fetch before creating a verification record;
- verification requires:
  - official host,
  - expected act title,
  - requested legal reference present in fetched text;
- a successful verification writes a `VERIFIED` record into `VerificationLedger`;
- a fetched official source that does not match the expected act/reference writes `UNVERIFIED`;
- provider receives the exact verification marker returned by the tool;
- model is instructed never to invent verification markers;
- G8 only releases a cited reference when the ledger contains VERIFIED evidence and the visible marker is present on the citation line;
- tool decisions and verification records participate in G9 audit completeness;
- public session response exposes only verification counts, not fetched source bodies;
- UI displays VERIFIED/UNVERIFIED counts.

## Security model

Verification is enforced in two layers:

1. `ToolBroker` rejects network hosts outside the configured allowlist.
2. `OfficialLegalSourceVerifier` independently validates HTTPS, host, response status/content type, expected act title and requested reference.

A successful HTTP response alone is **not** enough to create a VERIFIED record.
