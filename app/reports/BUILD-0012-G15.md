## Deterministic G15 acceptance test

G15 runs without live credentials.

### Safe path

A deterministic provider response without detected legal references must produce:

- HTTP 200;
- `status = DRAFT_PRESENTABLE`;
- `finalization = PASS`;
- answer released;
- audit result PASS;
- closed audit session.

### Citation-failure path

A deterministic provider response containing an unsupported legal citation must produce:

- HTTP 200;
- `status = BLOCKED`;
- `finalization = BLOCKED`;
- no `answer` field in the public response;
- blocked-reference metadata containing `MISSING_LEDGER_RECORD`;
- closed audit session.

### Invalid-route path

A non-DR primary skill must be rejected by the HTTP boundary with:

- HTTP 422;
- `error = INVALID_ROUTE`.
