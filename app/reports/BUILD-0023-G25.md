## Goal

Expose typed evidence to the local UI without forcing the browser to scrape inline verification markers from answer text and without exposing backend source bodies.

## Backend contract

`SessionExecutionResponse` now includes:

`evidence: PublicEvidenceItem[]`

Public evidence may contain:
- claim;
- kind;
- VERIFIED / SUPPORTED / UNVERIFIED status;
- official source URL and source tier;
- fetched timestamp;
- verification method;
- temporal mode and historical `asOf`;
- TEXT/PDF format;
- case scope and case signature;
- evidence/support hashes.

The sanitizer intentionally does not expose:
- backend `evidence` snippets;
- `supportQuote` stored in the ledger;
- source document bodies;
- internal audit details.

## UI

The local web app now renders an Evidence Bundle panel for both:
- DRAFT_PRESENTABLE responses;
- BLOCKED responses where verification metadata exists.

Cards distinguish:
- VERIFIED;
- SUPPORTED / evidence-linked;
- UNVERIFIED.

Historical evidence displays `Stan prawny: YYYY-MM-DD`.

Other visible metadata includes:
- source format;
- case scope;
- case signature;
- source tier;
- fetch date;
- official source link.

SUPPORTED cards explicitly state that the runtime did not semantically VERIFY the paraphrase.

## Privacy and bundle safety

Production bundle validation requires evidence UI markers while continuing to reject:
- provider API key variable names;
- PRAWO-HARDGATE source content;
- SKILL.md content markers;
- private-key material.

## Verification summary

Public session statistics now separate:
- verified;
- supported;
- unverified.

SUPPORTED never inflates VERIFIED.

## Acceptance

G25 deterministic gate verifies:
- historical VERIFIED evidence with `asOf`;
- current PDF evidence with `web_fetch_pdf`;
- EXACT_QUOTE case evidence;
- SUPPORTED proposition evidence;
- absence of backend-only evidence values in the serialized public bundle.

## Scope boundary

Inline markers remain part of HARD GATE integrity, but UI presentation no longer needs to parse them to explain evidence status.
