## Goal

A pinned source descriptor must never be treated as current merely because it exists in the runtime registry.

G19 performs a fresh ELI temporal decision before legal-reference verification.

## Current-law decision

For current law the checker:

1. loads the base act `/references`;
2. inspects `Inf. o tekście jednolitym`;
3. rejects a pinned t.j. whose ELI status is repealed/expired;
4. selects the newest in-force t.j.;
5. fetches metadata and references for that t.j.;
6. detects amendments after the t.j.;
7. compares the selected t.j. with the G18 descriptor;
8. chooses HTML or reports PDF-only;
9. permits verification only through a source state explicitly handled by the runtime.

### Red conditions

Current-law verification is fail-closed for:

- `REPEALED_CONSOLIDATED_TEXT`;
- `STALE_CONSOLIDATED_TEXT`;
- `POST_TJ_AMENDMENTS`;
- `NO_CURRENT_CONSOLIDATED_TEXT`;
- `SOURCE_METADATA_UNAVAILABLE`;
- unsupported source format.

A repealed/expired t.j. is therefore **red by default**.

## Historical exception requested by the user

A repealed text may be used only for an explicitly historical legal-state query.

The provider-visible tool has optional:

```json
{
  "asOf": "YYYY-MM-DD"
}
```

Rules:

- `asOf` is allowed only for a date strictly in the past;
- ELI metadata must prove that the base act was in force on that date;
- the runtime selects an official text/t.j. applicable to that date;
- a text that is repealed today may be used if its validity interval covers `asOf`;
- if the requested date is at/after repeal or expiration, result is `ACT_NOT_IN_FORCE_AT_DATE`;
- amendments between the selected historical text and `asOf` produce `HISTORICAL_POST_TJ_AMENDMENTS` and block verification;
- historical PDF-only text is handled by G20, not silently downgraded;
- the verification marker is explicitly historical:
  `✅ [VER: <source>, <fetch-date>, STAN NA <asOf>]`.

The ledger and audit trail persist:

- `temporalMode = CURRENT | HISTORICAL`;
- `asOf` for historical records.

This prevents a historical citation from being presented as current law.

- validity interval covers the historical date;
- no later amendment before `asOf`.

Observed:

- ledger VERIFIED;
- HARD GATE PASS;
- released answer contains `STAN NA 2020-06-01`.

- `asOf = 2021-01-01`;

Observed:
- `ACT_NOT_IN_FORCE_AT_DATE`;
- no verification content fetch;
- no ledger record;
- no public answer.
